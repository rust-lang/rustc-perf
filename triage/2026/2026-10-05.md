Caused by https://github.com/rust-lang/rust/pull/158936.
Before this PR, libstd.rlib (for x86_64-unknown-linux-gnu) was 11.7MiB, after this PR it is now 12.1MiB.
This is a 3.4% increase, I think that is most likely the cause of the regression since profiling shows the extra cost to be in run_linker.
Apart from linking, there are other clues as well: More time/count in metadata decoding, more query key hashing, larger query cache and the binary sizes are bigger, too.
It is unclear why this PR caused std to grow so much.
